# AI Customer Intelligence Platform

## Overview
An enterprise-grade end-to-end Data Science platform that helps businesses understand customers, predict churn, detect fraud, forecast sales, recommend products, and analyze customer sentiment.

## Tech Stack
- Python
- SQL
- PostgreSQL
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- FastAPI
- Power BI
- Docker
- AWS

## Business Problem

An e-commerce company wants to improve customer retention, increase revenue, reduce fraud, and provide personalized product recommendations using Data Science and AI.

The platform will:

- Predict customer churn
- Forecast sales
- Detect fraudulent transactions
- Recommend products
- Analyze customer sentiment
- Provide executive dashboards
